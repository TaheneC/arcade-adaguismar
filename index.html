Como publicar seu jogo

  1. Suba os arquivos

    Crie um repositório no seu GitHub e envie os arquivos do jogo. Inclua um index.html na pasta de publicação.

  2. Ative o GitHub Pages

    Em Settings → Pages, selecione Deploy from a branch, escolha a branch e a pasta do jogo e salve. Abra o endereço publicado para testar.

  3. Envie para revisão

    Preencha a ficha com o link do jogo e envie pelo GitHub ou compartilhe o arquivo com quem mantém o portal.
